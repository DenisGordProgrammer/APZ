## Короткий опис виконаних завдань

### Лабораторна робота №1: Тестування та розробка тест-кейсів
* Сформовано об'єкт тестування (електричний чайник) та виділено його базові компоненти.
* Написано набір із 10 детальних тест-кейсів (позитивні, негативні, boundary value, usability), які охоплюють функціонал продукту.

### Лабораторна робота №2: Хмарний хостинг на AWS S3
* Зареєстровано акаунт в екосистемі Amazon Web Services.
* Створено та налаштовано S3 Bucket для публічного хостингу статичних вебсторінок.

### Лабораторна робота №3: Віртуалізація в AWS EC2 та автоматизація
* Розгорнуто віртуальну машину на базі **Windows Server** у сервісі **AWS EC2**.
* Здійснено підключення через протокол **RDP**.
* Реалізовано кастомізацію робочого середовища: налаштовано автозапуск (`AutoRun` у реєстрі) інформаційного консольного дашборду з даними студента та системною діагностикою.
