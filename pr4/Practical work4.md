## 1. Тема роботи
Створення та налаштування віртуальної машини (EC2 Instance) на базі операційної системи Windows у сервісі Amazon Web Services (AWS EC2).

## 2. Хід виконання роботи

### Крок 1. Створення і налаштування екземпляру (Instance) в AWS EC2
1. Увійшов до власного акаунта на сайті [AWS Management Console](https://aws.amazon.com/) та перейшов до панелі управління сервісом **EC2** -> **Instances**.
2. Натиснув кнопку **Launch instance** та обрав операційну систему **Microsoft Windows** (у межах тарифу Free Tier).
3. Створив нову пару ключів (**Key pair**), обравши тип RSA та формат `.pem`, після чого зберіг цей файл на локальному комп'ютері (він необхідний для подальшої розшифровки пароля адміністратора).
4. Налаштував базову конфігурацію сховища (Configure Storage) та параметри безпеки.
5. Підтвердив створення екземпляру та дочекався, поки статус машини перейде в стан `Running`.

### Крок 2. Отримання зашифрованого пароля віртуальної машини
1. У панелі EC2 Instances обрав створену віртуальну машину.
2. Натиснув кнопку **Actions** -> **Security** -> **Get Windows password**.
3. Завантажив збережений на першому кроці файл приватного ключа (`*.pem`) та натиснув кнопку **Decrypt Password**.
4. Скопирував отриманий розшифрований пароль адміністратора для подальшого підключення.

---

### Крок 3. Підключення до створеної віртуальної машини через RDP
1. На локальному комп'ютері з ОС Windows натиснув комбінацію клавіш `Win + R`, ввів команду `mstsc` і натиснув Enter для запуску програми віддаленого робочого столу.
2. У полі **Комп'ютер (Computer)** ввів публічну IP-адресу (`Public IP`) моєї віртуальної машини та натиснув **Підключити (Connect)**.
3. У вікні авторизації обрав «Використовувати інший обліковий запис», ввів логін `Administrator` та розшифрований пароль.
4. Проігнорував попередження про сертифікат безпеки, натиснувши «Так», і успішно увійшов до робочого середовища Windows на віддаленій віртуальній машині.
